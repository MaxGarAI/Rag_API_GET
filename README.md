# Интеграция векторной памяти Pinecone и API для RAG-агента

Проект реализует базовый RAG-агент с интеграцией векторного хранилища **Pinecone**, модулем парсинга и индексации веб-страниц (URL), а также клиентом для обращения к открытым REST API.

---

## 🚀 Возможности

1. **Базовый RAG-агент и векторное хранилище Pinecone**:
   - Автоматическое подключение к Pinecone через официальный SDK (`pinecone>=10.0.0`).
   - Автоопределение размерности индекса (`1536` для `test-embedding-3-small`, `3072` для `test-embedding-3-large`).
   - Выполнение векторного поиска и тестового запроса с расчетом метрики релевантности (косинусное сходство).
   - Генерация ответов с помощью LLM (`openai/gpt-4o-mini` через OpenRouter) с опорой на извлеченный контекст и цитированием источников `[1]`, `[2]`.

2. **Обработка URL (парсинг, чанкинг, эмбеддинги, сохранение)**:
   - Загрузка HTML-страницы с заголовками User-Agent и автоопределением кодировки.
   - Очистка от скриптов, стилей, навигационных элементов через `BeautifulSoup`.
   - Интеллектуальное разделение текста на чанки заданного размера с перекрытием (overlap).
   - Батчевая генерация эмбеддингов через OpenRouter API.
   - Загрузка векторов и метаданных (`url`, `title`, `chunk_index`, `text`) в указанный namespace базы Pinecone.

3. **Запросы к открытым API**:
   - Выполнение HTTP GET-запросов к публичным REST API (`Open-Meteo`, `JSONPlaceholder`).
   - Обработка ошибок (таймауты, статус-коды HTTP 4xx/5xx, ошибки соединения, парсинг JSON).
   - Замер задержки ответа (latency) и нормализация данных.
   - Интеграция данных из внешних API в контекст RAG-агента в реальном времени.

## 📁 Структура проекта

- [`config.py`](config.py) — загрузка настроек из `.env` и сопоставление моделей эмбеддингов.
- [`vector_store.py`](vector_store.py) — класс `PineconeVectorStore` (управление подключением, расчет эмбеддингов, upsert, поиск, тест).
- [`url_processor.py`](url_processor.py) — функции извлечения текста страницы, чанкинга и сквозной индексации `index_url()`.
- [`api_client.py`](api_client.py) — клиент для выполнения GET-запросов к открытым API с валидацией и обработкой ошибок.
- [`rag_agent.py`](rag_agent.py) — класс `RAGAgent` (поиск по базе, интеграция API данных и синтез ответа через LLM).
- [`main.py`](main.py) — демонстрационный сценарий, выполняющий все этапы от проверки до ответа на вопрос.
- [`requirements.txt`](requirements.txt) — список зависимостей.

## 🛠 Запуск

Виртуальное окружение `.venv` уже настроено в рабочей директории.

Для запуска демонстрации всех компонентов выполните:
```powershell
.\.venv\Scripts\python.exe main.py
```
